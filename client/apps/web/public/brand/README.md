# Web brand assets

Only deployable web assets live here. The deliberately small set covers the practical web and platform contexts:

- `full-*`: complete supplied lockups for primary, inverse, and monochrome contexts
- `emblem-*`: marks for light, dark, and monochrome contexts

Use a `full-*` asset whenever the Bayes Institute name appears. There are deliberately no
standalone wordmark assets. The B emblem is reserved for compact brand and icon contexts.

The PWA icons, favicon, Apple touch icon, manifest, and Open Graph image are in this app's
`public/` root because browsers expect those URLs at the site root. They retain the existing B
emblem.
