# Web brand assets

Only deployable web assets live here. The deliberately small set covers the practical web and platform contexts:

- `logo-*`: full lockups for light, dark, and monochrome contexts
- `wordmark-*`: typography-only lockups for compact layouts
- `emblem-*`: marks for light, dark, and monochrome contexts

The original exhaustive source kit and platform/social derivatives were removed after this curation. Add a new asset only when it has a concrete product or deployment use.

The PWA icons, favicon, Apple touch icon, manifest, and Open Graph image are in this app's `public/` root because browsers expect those URLs at the site root.
