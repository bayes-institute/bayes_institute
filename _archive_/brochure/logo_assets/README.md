# Curated Bayes Institute logo assets

This directory intentionally retains a compact master set from the original
947-file export pack.

- `__guide__/` — brand guide and visual contact sheets.
- `all-optimized-svgs/` — canonical lightweight SVG variants for digital use.
- `print-assets/vector-pdf/` — vector PDF variants for LaTeX and print design.
- `web_deploy_pack/` — a minimal deployment set for logos, favicons, touch icon,
  and open-graph artwork.

Repeated raster dimensions, legacy EPS/TIFF exports, platform-specific social
templates, and duplicate PNG/WebP/AVIF/JPEG variants were excluded. The full
original pack was moved to `/tmp/bayes-logo-assets-full-backup` during this
session as a recoverable safety backup.
